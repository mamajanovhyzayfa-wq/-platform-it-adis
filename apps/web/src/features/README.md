# Web feature modules

Каждый каталог — один ограниченный доменный сценарий.

- `CommunityPage` / `SchedulePage` — только композиция вкладок и заголовок.
- Панели и вкладки — отдельные файлы, обычно до 400 строк.
- Общие подписи, форматтеры и чистые функции — в `shared.ts`.
- Запросы — в `src/api/<domain>.ts`; feature не вызывает `fetch` напрямую.
- Feature не импортирует внутренности другого feature. Общее выносится в
  `components/`, `hooks/` или `api/`.
- Новый крупный экран добавляется сюда, а не раздувает `pages/`.

Текущие модули: `community` (чаты, встречи, объявления, мероприятия),
`scheduling` (календарь, занятие, посещаемость, шаблоны, аудитории, согласования,
статистика, настройки).
