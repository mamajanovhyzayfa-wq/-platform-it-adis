# Итоговый результат ITadis

Документ сопоставляет 30 требований раздела 32 с реализацией в репозитории.
Статус `✔` означает, что есть серверная логика, модель БД, API, интерфейс
(там, где он предусмотрен), проверка прав и автоматические проверки.
Статус `◐` означает, что код готов, но для подтверждения нужен внешний ресурс:
ключ провайдера, DNS/TLS, EAS-аккаунт или production-сервер.

## Единая платформа

```text
Public site / Admin Web / Mobile
              │
              ▼
        NestJS API + Socket.IO
              │
     ┌────────┼─────────┐
     ▼        ▼         ▼
PostgreSQL  Redis   S3/MinIO
control DB +
branch DBs
     │
     ▼
LiveDigital, payments, SMTP/SMS, push,
calendars, AI, accounting
```

- Все клиенты работают через один `/api`; отдельного демонстрационного backend нет.
- Данные филиала выбираются по Host через `TenantContext` и Prisma-прокси.
- 41 модуль из ТЗ зарегистрирован в `AppModule`; это проверяет `module-registry.test.ts`.
- Веб- и мобильные кабинеты используют те же API и модели, что и административная панель.
- Внешние адаптеры при отсутствии ключей возвращают `not_configured`/`503`, а не фиктивный успех.

## Связность, а не отдельные страницы

- `apps/web/src/api/*` вызывает реальные маршруты backend; страницы без API-вызовов не считаются готовыми.
- `apps/mobile/src/api/api.ts` содержит типизированные вызовы тех же доменов; `(manager)` использует `/manager/overview` и `/manager/students`, `(admin)` — `/admin/dashboard`, `(parent)` — `/portal/parent`.
- `apps/api/src/nest/app.module.ts` подключает обязательные модули.
- Prisma-схема содержит модели всех доменов: филиалы, обучение, аттестация, видео, экономика, финансы, сообщения, уведомления, сертификаты, события, интеграции, backup.
- Критические операции пишут `AuditLog`, `Notification`, `CoinTransaction` и/или `IntegrationEvent` в одной транзакции с бизнес-операцией.

## Что нельзя подтвердить без внешних ресурсов

- LiveDigital: реальная комната, запись и вебхук.
- Платёжные провайдеры: реальная сессия оплаты и callback.
- SMTP/SMS/Expo Push: фактическая доставка.
- Google/Apple/календари/бухгалтерия: OAuth и реальные учётные записи.
- AI: ответ модели при заданном ключе и лимите.
- Домен, DNS и TLS: сертификат на балансировщике.
- Android/iOS: EAS build и подпись.
- Production: сервер, `DEPLOY_*`, резервное копирование на реальном volume.

Это ограничения среды, а не скрытые заглушки: при отсутствии ключей адаптеры
возвращают `not_configured` или `503`, а UI показывает понятное состояние.
