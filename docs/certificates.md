# Сертификаты об окончании курса

Модуль выдаёт именные сертификаты ученикам, печатает документ в HTML (сохраняется в PDF из браузера)
и даёт публичную проверку по коду без авторизации.

## Правила

- Сертификат выдаёт только администратор.
- Ученик должен быть записан на курс: проверяется `CourseEnrollment`.
- Одна пара «ученик — курс» — один сертификат (уникальный индекс). Отозванный сертификат занять пару
  продолжает: повторная выдача не создаётся, номер остаётся в истории.
- Номер `CERT-<год>-<5 цифр>` выдаёт атомарный счётчик `CertificateSequence`; параллельные выдачи
  не получают один номер.
- Код проверки — 12 символов из алфавита без похожих `0/O`, `1/I`, уникален в базе.
- Отзыв не удаляет документ: статус `REVOKED`, дата и причина видны при проверке.
- Выдача и отзыв пишутся в `AuditLog` и создают уведомление ученику (`CERTIFICATE_ISSUED`,
  `CERTIFICATE_REVOKED`); ошибка уведомления не отменяет операцию.

## API

| Метод | Путь | Роль | Назначение |
| --- | --- | --- | --- |
| GET | `/api/certificates` | ADMIN | Список с поиском по номеру, ученику, курсу, коду и фильтром статуса |
| GET | `/api/certificates/candidates?search=` | ADMIN | Ученики с курсами, по которым сертификата ещё нет |
| GET | `/api/certificates/my` | любая авторизованная | Сертификаты текущего пользователя |
| GET | `/api/certificates/verify/:code` | публично | Проверка подлинности по коду |
| GET | `/api/certificates/:id/html` | ADMIN или владелец | Печатный HTML |
| POST | `/api/certificates` | ADMIN | Выдача: `{ studentId, courseId, grade?, expiresAt? }` |
| POST | `/api/certificates/:id/revoke` | ADMIN | Отзыв: `{ reason }` (5–500 символов) |

Ответ проверки: `{ valid, expired, status, number, student, course, issuedAt, expiresAt, revokedAt,
revokeReason, issuedBy }`. Персональные данные ограничены именем ученика и названием курса.

## Интерфейс

- Админ-панель: раздел «Сертификаты» — выдача (поиск ученика, только доступные курсы, балл),
  печать, копирование ссылки проверки, отзыв с причиной.
- Публичная страница `/verify/:code` показывает статус документа и его данные.

## Настройка

`ADMIN_WEB_ORIGIN` — публичный адрес админ-панели, на него ведёт ссылка в печатном сертификате
(по умолчанию `APP_ORIGIN`, затем `http://localhost:3000`). В production укажите реальный домен.
